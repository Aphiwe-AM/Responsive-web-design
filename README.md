# freeCodeCamp - Responsive Web Design Certification

This repository contains my solutions and certification projects for the **Responsive Web Design Certification** from [freeCodeCamp](https://www.freecodecamp.org/). Throughout this curriculum, I learned the fundamentals of modern web development, including HTML5, CSS3, Flexbox, CSS Grid, and responsive design principles.

## Practice Projects & Courses

In addition to the certification projects, this curriculum covers foundational web design techniques through guided builds:
* **HTML & CSS Basics:** Cat Photo App, Cafe Menu, Colored Markers, Registration Form
* **CSS Box Model & Typography:** Rothko Painting, Photo Gallery, Nutrition Label, Accessibility Quiz
* **Intermediate CSS & Positioning:** Balance Sheet, Cat Painting, Piano, City Skyline
* **CSS Grid & Animations:** Magazine, Ferris Wheel, Penguin

## Technologies Used

* **HTML5** (Semantic markup, forms, accessibility best practices)
* **CSS3** (Flexbox, CSS Grid, Custom Properties/Variables, Media Queries, Animations)
